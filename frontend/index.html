The classifier recognises known tradecraft. The autoencoder, trained only on normal traffic, raises an alert on anything that deviates from it, including zero-day behaviour.

    From packet to verdict in five steps.

    The same pipeline runs on live packets from your network card and on the built-in attack simulator.

    1. Capture

      Packets are read from a network interface, or generated by the simulator, and grouped into bidirectional flows.

    2. Extract features

      31 CICFlowMeter-style features per flow: timing, volume, TCP flags, window sizes and port.

    3. Classify

      A 4-layer neural network (128-64-32 ReLU, softmax) assigns one of eight classes with a confidence score.

    4. Check for novelty

      An autoencoder measures distance from normal, and an embedding test measures distance from every known attack. Far from both means unknown.

    5. Correlate and respond

      Detections merge into incidents with severity, MITRE ATT&CK mapping, a response playbook and one-click blocking.

    Built for analysts, and for the room you are presenting in.

    Explains itself

    Gradient attribution shows which features pushed the network toward its verdict, so alerts are reviewable instead of mysterious.

    Finds the unknown

    Unusual traffic is flagged even when it matches no trained class, and is reported separately as a zero-day anomaly.

    Confirms with content

    A payload engine checks SQL injection, XSS, traversal, Log4Shell and reverse-shell signatures to back up flow-level alerts.

    Responds

    Block or quarantine sources manually, or switch on auto-response and watch hostile flows get dropped.

    Runs anywhere

    Pure Python and a browser. Windows, macOS or Linux, with no GPU and no deep-learning framework to install.

    Demo-ready

    Eight scripted attack scenarios, a guided demo mode with narration, and live detection-rate scoring against ground truth.
